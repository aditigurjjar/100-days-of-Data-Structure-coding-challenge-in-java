# 100-days-of-Data-Structure-coding-challenge-in-java

## 100 Days of DSA 🚀

This repository is a record of my **100 Days of DSA journey**.

I created this repo to practice Data Structures and Algorithms every day and improve my **problem-solving and logical thinking skills**. I’ll be adding the problems I solve each day along with their solutions.

The repository starts with basic concepts and gradually moves towards more advanced topics like **arrays, strings, searching, sorting, linked lists, stacks, queues, trees, graphs, recursion, sliding window, dynamic programming**, and more.

I’m sharing my daily practice here so that I can **track my progress, revise concepts easily, and hopefully help others who are also learning DSA**.

This is not just about completing 100 days — it’s about becoming better at solving problems one day at a time.

**100 Days → Daily Practice → Better Problem Solving 💻**
